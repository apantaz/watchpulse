# WatchPulse v0.4 — Backend Discovery API

Released: 2026-08-23

## Outcome

WatchPulse now exposes its locally published streaming catalog through a typed,
read-only discovery API. Browsing, filters, reference options, section rails,
and title details make zero upstream API requests.

## Delivered

- a FastAPI application factory with generated OpenAPI documentation;
- environment-configured, read-only DuckDB repository access;
- process health, catalog freshness, and sanitized unavailable-catalog errors;
- catalog regions, region-aware providers, scoped genres, languages, and filter
  ranges;
- one immutable global filter contract for region, providers, content type,
  genres, runtime, release years, rating, and language;
- one parameterized query engine with controlled state, ordering, section
  windows, pagination, and multi-provider title aggregation;
- WatchPulse Top 10 based on replaceable popularity ordering;
- New Releases based on content `release_date`;
- Recently Added based on provider `available_since` lifecycle evidence;
- Upcoming based on future `available_from` dates;
- Leaving Soon based only on known `expires_on` evidence;
- scoped title details by canonical TMDB ID and content type.

## HTTP surface

- `GET /health`
- `GET /api/v1/catalog/freshness`
- `GET /api/v1/catalog/regions`
- `GET /api/v1/catalog/providers`
- `GET /api/v1/catalog/genres`
- `GET /api/v1/catalog/filter-options`
- `GET /api/v1/discovery/top-10`
- `GET /api/v1/discovery/new-releases`
- `GET /api/v1/discovery/recently-added`
- `GET /api/v1/discovery/upcoming`
- `GET /api/v1/discovery/leaving-soon`
- `GET /api/v1/discovery/titles/{content_type}/{tmdb_id}`

## Validation

- All five sections apply the same global filters through real HTTP requests.
- Region and provider isolation pass for Greece, the US, Netflix, and Disney+.
- Runtime, release-year, rating, date-window, and pagination boundaries pass.
- Injection-shaped and unknown input is rejected before database execution.
- Missing catalogs return sanitized HTTP 503 responses without filesystem paths.
- Frontend-like reference, discovery, and detail requests make zero network
  connections.
- The complete v0.4 HTTP contract is present in generated OpenAPI documentation.
- The API was exercised against the real published Greece catalog.
- All 103 Python tests pass with 80.20% coverage, above the 65% gate.
- The warehouse rebuild passes all 193 dbt checks.

## Known limitations

- Retained development data currently covers Greece and four launch providers.
- Leaving Soon is empty while the first-release policy leaves `expiring`
  lifecycle ingestion disabled; expiration dates are never guessed.
- Runtime, richer metadata, and some lifecycle dates remain nullable until their
  source evidence or title enrichment is available.
- Discovery rails are bounded to 10 or 20 results; public pagination can be
  added when the frontend demonstrates a need.
- The API and serving database are local artifacts; public deployment, durable
  delivery, CORS policy, monitoring, and scheduled refreshes arrive later.
- No frontend is included in this version.
